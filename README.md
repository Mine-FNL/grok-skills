## Install

Clone the catalog into Grok's user skills directory. Nested `SKILL.md` files are discovered on the next session.

```bash
git clone https://github.com/Mine-FNL/grok-skills.git ~/.grok/skills/grok-skills
```

Or copy each skill to the top level:

```bash
git clone https://github.com/Mine-FNL/grok-skills.git
cp -R grok-skills/skills/* ~/.grok/skills/
```

Same files work in Claude Code and Codex. Claude plugin manifests live in [`.claude-plugin/`](.claude-plugin/).

## Skill format

Every pack is one folder, one file:

```text
skills/code-review/SKILL.md
```

Frontmatter Grok actually reads:

```yaml
name: code-review
description: "…"
when-to-use: code review, PR review, …
allowed-tools: Read, Grep, Glob, Bash
user-invocable: true
```
